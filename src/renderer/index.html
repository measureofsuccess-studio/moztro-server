About the App

Moztro adalah ekosistem kontrol dan pertukaran data lokal nirkabel berkecepatan tinggi yang menghubungkan perangkat Android dan PC Windows Anda secara instan tanpa memerlukan koneksi internet/cloud.

Fitur Utama

Overdrive
Real-time PC screen mirroring dengan kontrol touch & multi-gesture trackpad presisi tinggi.
Fast File Transfer
Pengiriman file & folder tanpa batas ukuran via local high-speed WebSocket & HTTP server.
View On Device (VOD)
Akses dan kelola seluruh penyimpanan Android langsung dari PC File Explorer via FTP.
Remote Control & Power Suite
Kontrol media, keyboard, touchpad, clipboard sync, hingga shutdown/restart PC jarak jauh.
